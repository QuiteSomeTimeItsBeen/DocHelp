# DocHelper

A small app prototype for helping with the review and diagnostics of children with cerebral palsy.

## Download
You can download it [here!!](https://github.com/QuiteSomeTimeItsBeen/DocHelp/releases/tag/cool)


## Building from Source
> [!IMPORTANT]
> Requires a **GCC compiler** to be installed (needed for CGo compilation, because I'm using Fyne).
To compile the Windows executable, run the following command in the root directory:

```bash
go build -ldflags=-s -o DocHelper0.1.exe .
```
